# Paw-To-Go 毛孩快充站（概念展示網站）

超充站旁的毛孩機能補給。這是展示用網站，不會實際收款或出貨。

- 前端：單一 `index.html`，部署在 GitHub Pages
- 後端：Google 試算表 + Apps Script（`backend/Code.gs`）
- 會員：Google 帳號登入（Google Identity Services）

`config.js` 三個欄位都留空時，網站會用內建的 14 個商品與模擬結帳運作。

## 後端功能

| 功能 | 說明 | 試算表工作表 |
| --- | --- | --- |
| 商品由後台管理 | 網站載入時讀取商品；改價格、取消勾選「上架」後重新整理即生效 | 商品 |
| 訂單寫入 | 結帳時寫入一列，金額由後端依試算表價格計算 | 訂單 |
| 會員 Google 登入 | 後端向 Google 驗證登入憑證，儲存毛孩名字與體重；會員結帳 9 折 | 會員 |

## 設定步驟

### 1. 建立試算表與 Apps Script

1. 到 Google 雲端硬碟新增一份空白試算表。
2. 選單「擴充功能 → Apps Script」，把編輯器裡的內容全部換成 `backend/Code.gs`，存檔。
3. 上方函式選單選 `setup`，按「執行」，依畫面授權。回到試算表會看到「商品、訂單、會員」三張工作表。
4. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：我
   - 誰可以存取：所有人
5. 複製結尾為 `/exec` 的網址，填到 `config.js` 的 `APPS_SCRIPT_URL`。

### 2. 建立 Google 登入用戶端 ID

1. 到 Google Cloud Console → API 和服務 → 憑證 → 建立憑證 → OAuth 用戶端 ID。
   第一次會要求先設定 OAuth 同意畫面（對象選「外部」，填應用程式名稱與 Email 即可）。
2. 應用程式類型選「網頁應用程式」，在「已授權的 JavaScript 來源」加入網站網域，例如 `https://你的帳號.github.io`（不含路徑）。
3. 複製用戶端 ID，填到兩個地方：
   - `config.js` 的 `GOOGLE_CLIENT_ID`
   - Apps Script 裡 `Code.gs` 最上方的 `GOOGLE_CLIENT_ID`
4. 改完 `Code.gs` 後要「部署 → 管理部署作業 → 編輯 → 版本選『新版本』→ 部署」，網址不變。

同意畫面若停在「測試中」，只有加入測試使用者名單的 Google 帳號能登入；要讓所有人登入請按「發布應用程式」。

### 3. 更新網站

改完 `config.js` 後提交並推送，GitHub Pages 約一分鐘內更新。

## 注意事項

- Apps Script 網址是公開的，任何人都能送出展示訂單；後端已限制數量、品項並以試算表價格為準，訂單上限 5000 筆。
- 「預估食材成本」只留在試算表，API 只回傳平均毛利率。
- 「會員」工作表會存登入者的 Email 與姓名，報告結束後如不需要可自行清除。
